# Lesson 0. ROS2란 무엇인가

## 1. ROS2는 "OS"가 아니다

이름에 Operating System이 들어가지만, ROS2는 리눅스 같은 커널이 아닙니다.
**로봇 소프트웨어를 만들 때 반복적으로 필요한 것들을 미리 만들어 둔 프레임워크 + 라이브러리 모음**이라고
생각하면 됩니다. 예를 들면:

- 여러 프로그램(센서 처리, 모터 제어, 경로 계획 등)이 서로 **통신**하는 방법
- 코드를 **패키지 단위**로 나누고 빌드하는 표준 방법 (`colcon`)
- 로그, 시간 동기화, 좌표계 변환(TF), 시각화 도구 등

로봇 하나에는 보통 "카메라에서 영상 받기", "장애물 인식하기", "바퀴 속도 계산하기" 같은
독립적인 작업들이 동시에 돌아갑니다. 이 작업들을 각각 **별도의 프로그램(노드)**으로 만들고,
ROS2가 이 프로그램들끼리 데이터를 주고받게 해줍니다.

## 2. ROS1과 무엇이 다른가 (아주 간단히)

| | ROS1 | ROS2 |
|---|---|---|
| 통신 방식 | 자체 프로토콜 (`roscore` 필수) | 표준 **DDS**(Data Distribution Service) 기반 |
| 중앙 서버 | `roscore`라는 마스터 노드 필요 | **중앙 서버 없음** (노드들이 서로 자동으로 찾음) |
| 실시간성 / 임베디드 | 취약 | 실시간 시스템, 소형 임베디드 지원 강화 |
| 지원 OS | 사실상 Linux 전용 | Linux/Windows/macOS |

지금은 "ROS2는 `roscore` 없이 노드들이 알아서 서로를 찾는다" 정도만 기억하면 충분합니다.

## 3. 핵심 개념 5가지

앞으로 하나씩 실습하겠지만, 먼저 그림을 그려봅시다.

```
[카메라 노드] --토픽(/image)--> [인식 노드] --토픽(/detected)--> [제어 노드]
                                      ^
                              서비스 호출: "지금 몇 개 인식했어?"
```

1. **노드 (Node)**
   하나의 실행 프로그램 단위. "카메라 드라이버", "장애물 회피 로직" 등이 각각 노드입니다.
   `ros2 run <패키지> <실행파일>` 로 실행합니다.

2. **토픽 (Topic)**
   노드 간 **비동기 단방향 데이터 스트림**. 하나의 노드가 "발행(publish)"하면,
   관심 있는 여러 노드가 동시에 "구독(subscribe)"할 수 있습니다.
   예: 카메라 노드가 `/image` 토픽에 계속 이미지를 뿌리면, 여러 노드가 동시에 받아볼 수 있음.
   → 라디오 방송과 비슷합니다. 보내는 쪽은 누가 듣는지 몰라도 됩니다.

3. **서비스 (Service)**
   **동기적인 요청-응답(1:1)**. "질문 하나 던지고 답 하나 받기".
   예: "지도 저장해줘" 요청 → "저장 완료" 응답.

4. **액션 (Action)**
   서비스와 비슷하지만 **오래 걸리는 작업**을 위한 것. 중간 진행상황(피드백)을 계속 받을 수 있고
   취소도 가능합니다. 예: "저기까지 이동해줘" (이동 중 진행률 알려주고, 중간에 취소 가능).

5. **파라미터 (Parameter)**
   노드가 실행될 때 설정할 수 있는 값. 예: 카메라 노드의 "해상도", "프레임레이트" 같은 설정값.

이 5개 중 실습은 **노드 → 토픽 → 서비스 → 파라미터 → 액션** 순서로 진행할 예정입니다.
(토픽/서비스가 실무에서 압도적으로 많이 쓰이기 때문에 먼저 다룹니다.)

## 4. 패키지와 워크스페이스

- **워크스페이스(workspace)**: 여러 ROS2 패키지를 모아 빌드하는 작업 폴더. 보통 `~/ros2_ws/src/` 아래에
  패키지들을 두고, `colcon build`로 한꺼번에 빌드합니다.
- **패키지(package)**: 노드(실행파일), 설정, launch 파일 등을 담는 단위. 하나의 "기능 모듈"이라고 생각하면 됩니다.
- 언어는 크게 두 가지: **Python (rclpy)**, **C++ (rclcpp)**. 우리는 진입장벽이 낮은
  **Python(rclpy)**로 먼저 시작합니다.

## 5. 이번 세션 환경에 대한 안내

이 실습 환경(클라우드 컨테이너)에는 화면(GUI)이 없어서, RViz나 Gazebo처럼 창을 띄우는 도구는
직접 보여드릴 수 없습니다. 대신:

- `ros2 topic echo`, `ros2 node list`, `ros2 service call` 같은 **커맨드라인 도구**로 결과를 확인
- 실행 로그를 그대로 캡처해서 보여드리는 방식으로 진행

또한 이 환경은 공식 ROS2 APT 저장소(`packages.ros.org`)에 네트워크가 막혀 있어서,
**RoboStack**(conda/micromamba 기반 배포판)으로 ROS2 Jazzy를 설치합니다.
자세한 내용은 다음 Lesson([`01-install.md`](01-install.md))에서 다룹니다. (지금 백그라운드로 설치 진행 중입니다.)
